# 拒绝借钱截图工具

> 「兄弟，不是我不帮你，我的钱刚存了定期。」

一个帮面子抹不开的朋友婉拒借钱的个人整活小工具。填好金额、存期等参数，就能快速生成一张**模拟的定期存款截图**，给难以开口的「不借」找个聊天借口。

**免费使用，没有商业化计划。** 没有会员、付费解锁或银行服务，也不是理财产品。这个项目就是想把一件小事做得简单、顺手。

## 为什么做这个

有些人不想把钱借出去，只是不知道怎么拒绝。这个项目提供一个「钱存定期了」的聊天道具，帮助缓解开口时的尴尬。

它只负责生成模拟图片，不连接银行、不查询账户、不办理存款，也不会让图片变成真实的资金证明。没有截图也可以直接说「这次不方便借」；拒绝借钱不需要证明自己的余额。

## 怎么用

1. 打开[工具页面](https://jieqian.yeedit.xyz/)，直接编辑预览中的金额、年利率、存期和日期。第一次可点击「试试修改金额」。
2. 按需要调整卡号 / 账户尾号、手机时间、网络、信号和电量。
3. 检查预览，选择清晰度，点击「导出 PNG」。

**PC 端双击、手机端点按预览中的数值或图标修改。** Enter、保存按钮或点击外部提交；Esc / 取消放弃。点击「标出可编辑位置」查看编辑范围，键盘用户也可 Tab 选中内容后按 Enter 编辑。

完整表单默认收起，点击「全部参数」随时展开；热点开关和导出清晰度始终可见。引导与编辑标记不会出现在导出的图片中。

| 功能     | 说明                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 就地编辑 | 金额、利率、产品存期、日期（含时间轴）、尾号、时间、网络 / 信号、电池和底部显示均可在预览上双击修改 |
| 日期联动 | 默认按存期计算到期日；修改到期日会改为手动日期，选择固定存期会恢复自动计算                          |
| 输入校验 | 金额、日期、电量等不合法时提示原因，防止错误参数被直接导出                                          |
| 本地保存 | 有效参数自动保存在当前浏览器，刷新可恢复；重置可清空                                                |
| PNG 导出 | 1×：390 × 844；2×：780 × 1688；3×：1170 × 2532                                                      |
| 无需注册 | 图片在浏览器中生成，无需登录或上传参数                                                              |

### 一些小细节

- 初次访问与重置时，手机时间使用浏览器本地时间，存入日期默认为 16 天前；已保存的参数优先恢复。
- 卡号与账户使用固定示例前缀，各自搭配随机的四位尾号。尾号可以手动修改，支持前导零，也可以重新随机生成。
- 利息始终由金额、利率和存期计算，不单独填写。手动到期日期按实际天数估算。
- 「底部文字半截显示」默认开启，只改变底部说明文字的裁切效果，不改变图片尺寸。
- 新配置默认关闭热点提示，顶部中间留白，不绘制水滴、刘海或摄像头孔。可随时打开「热点提示」显示连接 1 台设备；旧版本保存的配置会保留原来的热点显示，重置后采用新默认值。
- PNG 只包含模拟手机画面，不包含外层编辑器、硬件边框和网站免责声明。**导出后也不会因此成为真实凭证。**

## 数据与隐私

参数编辑、计算和图片生成都在浏览器内完成；应用没有实现向服务器提交这些参数或生成图片的接口。有效配置保存在当前浏览器的 `localStorage` 中，可通过「重置 → 清空并重置」清除。

## 本地运行

需要 Node.js 22.18+，推荐 Node.js 24。

```sh
git clone https://github.com/JerryZhi/bu-jie-qian.git
cd bu-jie-qian
npm ci
npm run dev
```

打开终端显示的本机地址。

```sh
npm test         # 日期、利息、输入校验与配置恢复测试
npm run build    # TypeScript 检查与生产构建
npm run preview  # 本地预览生产构建
```

建议使用较新的 Chrome / Edge。字体取自当前设备，不同系统的导出外观可能略有差异。

## 实现与计算

React + TypeScript + Vite，PNG 由 `html-to-image` 生成。页面不加载第三方字体、远程图片或分析脚本。

- 固定存期利息：本金 × 年利率 ÷ 100 × 月数 ÷ 12。
- 手动到期日利息：本金 × 年利率 ÷ 100 × 实际天数 ÷ 365。
- 日期差按 UTC 日历日计算；按月到期遇到月末会取目标月最后一天；利息四舍五入到分。

这些只是用于模拟界面的单利估算，不代表银行实际计息规则，也不构成理财建议。

```text
src/App.tsx            参数表单、页面说明与导出
src/PreviewEditor.tsx  预览就地编辑（PC 双击 / 手机点按 / 键盘）
src/PhoneScreen.tsx    模拟手机画面
src/domain.ts         配置、日期、校验与计算
tests/domain.test.ts   计算与配置回归测试
docs/DEPLOYMENT.md     服务器部署与回滚
```
